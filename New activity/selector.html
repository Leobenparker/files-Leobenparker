1. List out the different ways to select an item.

By element, class, ID, attribute, group selector, descendant selector, and pseudo-class selectors.

2. What is the difference between an ID and a Class?

An ID is unique and used once per page. A class can be reused on multiple elements.

3. What is the difference between a SPAN tag and a DIV tag?

SPAN is inline and used for small text parts. DIV is block-level and used for sections.

4. What is the difference between a DIV tag and HEADER, MAIN, or FOOTER?

DIV is generic. HEADER, MAIN, and FOOTER are semantic tags with meaning for page structure.

5. What are the different ways to select a color?

Color names (red), HEX (#ff0000), RGB (rgb(255,0,0)), RGBA (rgba(255,0,0,0.5)), HSL.
