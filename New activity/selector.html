2. what is the difference between an ID and a Class?

An ID is a unique identifier for an element, while a class can be applied to multiple elements.

3. what is the difference between a span tag and a div tag?

A span tag is an inline element used for styling or grouping inline content, while a div tag is a block-level element used for structuring the layout of a webpage.
